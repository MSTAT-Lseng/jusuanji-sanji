# jisuanji-sanji

计算机三级网络技术考试题库。本项目使用 `Electron` 制作。题库来自无忧考吧。共 `1666` 道题。适合考前复习。

## 特性

 - 共 `1666` 道题，包含选择和操作题；
 - 包含完整的试题解析，选择题自动判题；
 - 可以跳转到指定题目；
 - 安装方便快捷。

## 使用

 - 安装所需要的依赖

```bash
npm install
```

 - 运行项目

```bash
npm start
```

或者前往 **Release** 页面下载打包的 exe 安装包。
